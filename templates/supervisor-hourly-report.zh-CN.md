# Supervisor 每小时中文进展模板

本文件只定义给人的汇报方式，不改变任务调度、执行权限、协议状态或验收标准。机器字段和原始证据保持原样；不要为了套模板增加执行、通知、存储或额外模型调用。

## 写作要求

先回答三件事：**本轮实际推进了什么、现在卡在哪里、是否需要用户处理。** 用自然中文，不逐项朗读内部检查清单。

正常轮次建议约 300—600 个汉字；没有新进展时更短。字数不是硬限制，不能省略关键风险或漏掉已选项目。删除空标题，不用装饰性大字、进度百分比或没有依据的预计完成时间。

只将有可核对前后证据的内容称为“新增”“本小时完成”“没有变化”。仅有当前快照时，写“本轮核实”；不能把几天前的成果说成刚刚完成。没有读到、读取失败、确实没有记录，是三种不同情况。

## 正常结构

```markdown
# Bridge 每小时进展｜MM-DD HH:mm（北京时间）

**本轮结论：**〈一句话说明实际进展或主要阻塞，不把服务在线写成项目完成。〉

### 本轮进展
〈本轮重点项目：具体做了什么、得到什么证据、还有什么未验证。普通轮转用“本轮重点是……”即可；只有临时插入紧急问题时才简述原因。〉

### 项目概况
〈每个已选项目一行：项目名｜当前进展或具体阻塞。未深入审阅的项目明确写“本轮未展开”，不要替它下验收结论。〉

### 下一步与需要你处理的事
〈下一步由谁做、需要什么条件。没有明确人工事项则说明“不需要你现在操作”；证据不足时说清尚不能判断，不能强行给出无需处理的结论。〉

〈必要时附少量直接支持本轮结论的证据链接；没有可用链接就给最小必要的文件/报告定位，不编造链接。〉
```

## 状态的中文表达

下表仅用于理解和翻译，**不要把整张对照表复制到每小时汇报**。

| 内部事实 | 给用户的表达 | 不可混淆的边界 |
| --- | --- | --- |
| STAGED_INPUT_SUBMITTED | 任务申请已提交，尚未确认接收 | 不能说已经开始执行 |
| COMMAND_READY | 任务已接收，等待开始 | 不能说模型正在工作 |
| CODEX_RUNNING | 正在执行〈具体任务〉 | 没有最新执行证据时说明尚未确认 |
| REPORT_READY | 执行结果已回传，等待审阅 | 不等于项目或目标已经完成 |
| SUCCESS | 本次任务的〈具体验收〉已通过 | 项目完成仍需目标级验收；模型自报不代替验证 |
| BLOCKED | 本次任务受阻：〈具体原因〉 | 区分模型可继续排查与真正需要人工的事 |
| RECOVERY_REQUIRED | 中断现场尚待核清，暂不重跑 | 保留未确认副作用，不把中断说成成功 |
| HUMAN_REQUIRED | 〈按最新关联记录描述人工、验证或恢复依赖〉 | 用户已做完时写“等待验证/恢复”，不再要求重复操作 |
| deferred-this-pass | 本轮未展开，留待后续轮转 | 不暗示已进行代码或成果审阅 |
| recovery-awaiting-evidence | 等待补充恢复证据；其他项目按计划推进 | 不把项目局部问题说成全系统停机 |
| worker_available=false | 本轮无法确认执行端可接收新任务，暂不发布新任务 | 不能把通信超时直接断言为电脑关机，也不暗示已经完成资料审阅 |

初始化项目尚无执行报告时，应写“等待首次规划”，不能仅因状态为 REPORT_READY 就说“结果已回传”。是否完成资料审阅也必须按本轮实际动作描述。

## 简洁但不丢事实

正常汇报不展示轮转下标、完整队列计算、布尔字段、进程号、长哈希、整段错误栈或重复的安全宣言。它们仍参与内部核验和已有审计；用户要求排障或结论确实依赖某个值时，再用“中文解释 + 最小原始标识”呈现。

保留真实项目名、模型名、必要文件名即可，不用强行翻译专有名称。任务申请、正式接收、开始执行、验收通过必须分开描述。通知状态也要区分“已尝试”“发送方已接受”“用户已看到”。

模板获取失败时，使用“结论 → 本轮进展 → 每项目一行 → 下一步/人工事项”的简版。模板不可用本身不是新增的执行阻塞，也不授予任何执行权限。

## 表达示例（虚构，仅示范措辞）

**任务申请刚提交：**“已提交项目甲的修复任务申请，尚未确认本机接收。项目乙本轮未展开。接下来等待执行端接收回执；目前没有需要你操作的事项。”不能写“项目甲已开始修复”。

**只有资料审阅：**“本轮核实了项目甲的失败原因，但执行端状态无法确认，因此没有提交新任务。下一步先确认连接恢复；暂不能判断是否需要你处理。”不能写“本小时完成修复”。

**局部恢复问题：**“项目甲的中断现场仍有一项共享配置变更待核清，暂不重跑；项目乙已回传执行结果，等待审阅。本轮没有发现新的完成证据。”是否允许项目乙继续，仍由实际协议与当前证据决定。
